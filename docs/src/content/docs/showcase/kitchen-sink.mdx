### Remaining parity gaps before full `add --all`

- Starlight's dedicated example depth (e.g. multiple aside-content permutations on separate pages) is broader than this single-page parity summary.
- Link-card semantics can be promoted from styled cards to dedicated reusable shadcn wrappers for stricter behavior parity.
- A few official Starlight component affordances (fine-grained transitions/focus nuances) still need side-by-side tuning under `astro-default`.
