The `Hero` override maps Starlight hero actions to shadcn button variants. Supported values:

| Variant | Style |
| --- | --- |
| `default` / `primary` | Filled primary button |
| `secondary` | Muted secondary fill |
| `outline` | Bordered ghost fill |
| `ghost` / `minimal` | Transparent hover |
| `destructive` | Destructive tint |
| `link` | Text link style |
