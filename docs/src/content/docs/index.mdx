## Install

```bash
pnpm add @astrojs/starlight starlight-shadcn @astrojs/react
```

```js title="astro.config.mjs"
starlight({
	customCss: ['./src/styles/global.css'],
	plugins: [starlightShadcn()],
});
```

Then paste your palette into `global.css`. The [Getting Started](/starlight-shadcn/guides/getting-started/) guide covers each step.
