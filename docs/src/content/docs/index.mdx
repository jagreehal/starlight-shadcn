**28 component overrides** — header, sidebar, search, hero, footer, TOC, and more.

**Bring your own shadcn tokens** — `--background`, `--primary`, `--sidebar-*` mapped onto Starlight's `--sl-*` variables. Paste a palette from shadcn/create, tweakcn or shadcn.studio and the whole site follows.

**React Aria islands** — drop shadcn components into MDX via `@astrojs/react`.

```bash
pnpm add @astrojs/starlight starlight-shadcn @astrojs/react
```

Browse the [showcase](/starlight-shadcn/showcase/overrides/) or read the [plugin API](/starlight-shadcn/reference/plugin-api/).
